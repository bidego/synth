# Bancos de muestras

Datos de instrumentos General MIDI en formato WebAudioFont (S. Surikov, https://github.com/surikov/webaudiofont),
copiados con `scripts/fetch-sounds.sh`.

- `*_FluidR3_GM_*`: FluidR3 GM SoundFont, (c) 2000-2002, 2008 Frank Wen. Licencia estilo MIT: se debe mantener este aviso de copyright.
- `*_GeneralUserGS_*`: GeneralUser GS, S. Christian Collins (https://www.schristiancollins.com/generaluser.php).

Nombres: `PPP0_<banco>_sf2_file.js` (instrumento GM PPP) y `128NN_<kit>_<banco>_sf2_file.js` (pieza NN de bateria).
